# Changelog

All notable changes to this package will be documented in this file.

## [1.1.0] - 2026-07-16

### Added
- Added support for macOS 26 and Windows 10 installations by discovering and supporting standard `Antigravity` naming conventions for folders and executable binaries.

## [1.0.0] - 2026-01-06

### Added
- Initial release of Antigravity Editor integration for Unity
- Auto-detection of Antigravity installations on macOS, Windows, and Linux
- Support for opening scripts in Antigravity from Unity
- Project generation (.csproj and .sln files) for IntelliSense support
- Configurable project generation settings in Unity Preferences

### Based on
- Forked from `com.unity.ide.vscode` v1.2.3
