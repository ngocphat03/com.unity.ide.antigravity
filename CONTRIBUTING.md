# Contributing to Antigravity Editor for Unity

Thank you for your interest in contributing! 🎉

## How to Contribute

### Reporting Bugs

1. Check if the issue already exists in [GitHub Issues](https://github.com/ngocphat03/com.unity.ide.antigravity/issues)
2. If not, create a new issue with:
   - Unity version
   - OS and version
   - Antigravity version
   - Steps to reproduce
   - Expected vs actual behavior

### Suggesting Features

Open an issue with the `[Feature Request]` prefix in the title.

### Pull Requests

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test in Unity Editor
5. Commit with clear messages
6. Push and open a PR

## Code Style

- Follow C# naming conventions
- Use `AntigravityEditor` namespace
- Add XML documentation for public APIs
- Keep methods focused and small

## Testing

Run tests via Unity Test Runner:
1. Open `Window > General > Test Runner`
2. Select `EditMode` tab
3. Click `Run All`

## Questions?

Open a [Discussion](https://github.com/ngocphat03/com.unity.ide.antigravity/discussions) or create an issue.
